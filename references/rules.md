# STE working summary

This is a condensed, paraphrased working list. It is not the official text. Check the current ASD-STE100 issue for formal work.

## Contents
1. Word substitutions
2. Sentence patterns
3. Warnings and cautions

## 1. Word substitutions

| Avoid | Use |
|---|---|
| utilize, employ | use |
| commence, initiate | start |
| terminate | stop, end |
| prior to | before |
| subsequent to | after |
| assist | help |
| ensure | make sure (or write the command directly) |
| should (as advice) | must (if required), or rewrite |
| approximately | about |
| in order to | to |
| perform | do (or use the specific verb) |
| failure to | if you do not |
| ascertain, verify (vague) | examine, measure, make sure |

Rule of thumb: if a simpler word keeps the exact meaning, use it. If the word is a recognized technical name for the domain, keep it.

## 2. Sentence patterns

- Command: `Verb + object (+ condition/location).` "Turn the knob clockwise."
- Condition: put the condition first. "If the light is red, stop the engine."
- Result of a step: separate sentence in the present tense. "The pump starts."
- Two actions: two steps, in order of doing.
- Notes: short, after the step, in their own paragraph.

## 3. Warnings and cautions

- Place before the step.
- State the hazard and the consequence in plain words.
- Use the imperative for the protective action.
- Do not bury a warning inside a step.

## 4. Noun clusters

Limit: three nouns in a row. Fix by adding a preposition or a verb.
- "Hydraulic system pressure relief valve" becomes "the relief valve of the hydraulic system".

## 5. Common failures

- Passive voice in steps ("The valve must be closed").
- Two actions in one sentence.
- A synonym swap that changes the term for the same part.
- A -ing form for a tense ("The pump is running" becomes "The pump runs").
- An idiom that machine translation will break.
